# Liquid Hub

Eu quero criar um site que seja uma central. Basicamente, eu tenho vários sites e vários sistemas de diversos tipos de falanges, como, por exemplo:

- mods para Zombie de Sims 4

- sites de web design

- meu portfólio

- sites sobre web

- web coding

- sites de skills para IDE

Enfim, a verdade é que ela é gigante.

Eu queria uma central como se fosse um grande hub para todos os meus sites, com a estética de Glassmorphism da Apple nova, aquela estética de Liquid Glass com aquele efeito de Liquid Glass. O efeito de Liquid Glass precisa ser bem aparente, idêntico ao do iOS 27.

É importante que seja intuitivo, fácil para o usuário que está entrando já entender do que se trata o site. Também é importante que seja um portal para mim, onde eu, como administrador, consiga criar novos projetos, novos websites, se novos projetos surgirem, novos websites surgirem, e adicionar ao grande hub com facilidade, como um dashboard de gerência. Nada para o usuário, só esse login para administrador, onde eu consiga cadastrar novos serviços e alterar os detalhes da página do hub por uma página de gerenciamento do dashboard, tudo muito premium e bem pensado, coeso com animações elegantes.
